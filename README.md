Getting started

Prerequisites
- Any modern browser
- Optional: Node.js/npm if you want to use a local dev server tool

Run locally (simple)
1. Clone the repository:
   git clone https://github.com/Stanlee97/Abia-state.git
2. Open index.html in your browser:
   - Double-click the file, or
   - Serve it with a simple HTTP server to avoid CORS issues:
     - Python 3:
       python -m http.server 8000
       Then open http://localhost:8000
     - Node (http-server):
       npx http-server -p 8000
       Then open http://localhost:8000
